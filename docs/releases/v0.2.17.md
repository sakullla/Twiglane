## 内存与性能

- 历史多文件差异离开视口后释放内容，切换页面释放本地差异，减少长时间浏览时的内容驻留。
- 高亮任务限制并发和输入规模，取消后停止排队任务；超大文本仍完整显示，超预算部分按纯文本展示。
- 减少本地差异的重复 Git 调用，并限制未跟踪大文件的列表统计量。单机样例中，10 次差异读取从约 1.46 秒降至 0.84 秒；含 104 MB 未跟踪文本的 3 次刷新从约 4.16 秒降至 0.21 秒。超预算文件的列表行数暂留空。
- 相同差异刷新复用排版输入；提交所在分支查询限制并发，修复旧响应覆盖缓存结果的问题。

## 分支、合并与同步

- 历史详情可查看包含当前提交的本地和远程分支。
- 合并前可按提交和文件审阅将带入的改动。
- 远程分支短名被占用时，可以使用新的本地名称检出。
- 多远程仓库支持指定目标推送及依次推送；支持取消正在进行的远程同步。
- 仓库切换列表显示当前分支，并完善相关确认和弹层交互。

验证数据和限制见 [v0.2.17 验证记录](https://github.com/sakullla/Twiglane/blob/v0.2.17/docs/verification/v0.2.17/verification.md)。性能数字是 Windows 生成仓库的单机样例，未测量固定内存降幅或跨平台 WebView 帧率。

Windows x64：NSIS 安装包；macOS Apple Silicon：DMG；Linux x64：deb / AppImage。

测试分发：Windows 未签名；macOS 使用固定自签证书，未经过 Apple 公证。需要系统 Git；Windows 缺少 WebView2 时安装器会联网下载。

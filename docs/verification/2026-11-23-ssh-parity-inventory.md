# SSH 工作树入口核对

需求范围见《Twiglane 远端 SSH 仓库全功能支持》的 R1–R6。逐项复验时，分别从 Twiglane 主机和 Cliora 主机簿选择同一测试账号，再用另一主机的同名仓库核对隔离。开发证据有两类。Windows WebView 经 SSH 连接 Debian x64 或 ARM64 时，从真实界面触发操作。Agent 协议测试用独立仓库检查 Git、文件系统、回执和错误分支。发行验收还需记录对应候选、桌面及远端版本、架构和实际结果。

| 功能与用户入口 | 前置状态和应核对的结果 | 现有开发验证 |
|---|---|---|
| 打开、最近重开、切换、移除最近记录 | 输入 SSH 主机与绝对路径。从欢迎页、标题栏或命令面板重开。切换同名仓库时显示实际主机、分支和改动。移除最近记录后远端目录仍在。 | Debian x64 和 ARM64 直接打开。Debian 的两条主机入口和旧回执恢复已有 WebView 与实际 SSH 证据。重启持久化与同名隔离由 Rust 和前端回归核对。 |
| 新建、克隆、后台克隆 | 在 SSH 选择器指定主机、目标路径或克隆地址和父目录。新建检查 `git rev-parse`，克隆比较提交哈希。后台完成写入最近记录并保留当前仓库。旧操作核对原回执。移动已完成的仓库后，新操作可重用原路径。 | Windows Agent 使用真实 Git 验证创建、克隆及原回执。Debian x64 Agent 模拟预检后、init 与 clone 进程启动后替换目录，替换目录无 `.git`。Windows WebView 经 Debian x64 验证两条主机入口及原路径复用。后台克隆覆盖命令面板及不切换的前端回归。 |
| 新建或克隆待确认 | 从原主机和路径重连时保留旧操作 ID。检查目录后选择「已核对，开始新操作」，桌面校验当前旧 ID 并生成新 ID，远端仍保留原回执。 | 桌面 Rust 验证重启和并发确认。Agent 真实 Git 测试验证新操作成功且旧记录仍待确认。前端回归覆盖两按钮、路径切换及安装确认。 |
| 项目管理、关联、远端发现、项目切换 | 从项目管理纳入当前仓库或检查 SSH 路径。发现结果待确认后才保存清单。储存已核验的主机 UUID 和远端路径。标题栏、欢迎页、命令面板和项目行从主机绑定重开。 | 项目投影和管理面板回归检查确认、同名隔离和绑定参数。Agent 通过真实 Git 工作树验证目录发现与仓库归属。 |
| 工作区状态、查看与删除 | 打开主仓知道附属位置。标题栏和分支管理可切换。删除时对照预览身份、脏状态及实际删除路径，取消后目录与 Git 引用保持。 | Debian x64 WebView 两条主机入口覆盖工作区切换及删除。Agent 覆盖已变化的 common Git 目录和禁止删错目标。 |
| 改动列表、差异与审阅 | 改动侧栏、文件右键、命令面板、键盘导航和审阅标记使用当前工作树。文件内容变化后清除失效标记。重启后读取对应的提交草稿和审阅标记。 | Debian x64 WebView 关键路径、Agent 真实索引和差异回归。草稿及进度持久化由 Windows Rust 和前端测试核对。 |
| 文件、块、行及批量暂存与撤出 | 工具栏、文件右键、快捷键和命令面板操作后对照 `git diff --cached` 与工作树 diff。 | Debian x64 真实 SSH Git 路径及 Agent 协议套件。 |
| 放弃、提交、修订、撤销、恢复 | 文件右键与提交区恢复菜单先显示影响。确认后核对索引、提交数、HEAD 和留下的改动，取消时无写入。 | Debian x64 真实 SSH Git 路径及 Agent 协议套件。 |
| 历史、图谱、详情、比较与文件历史 | 通过视图按钮、文件右键、命令面板、筛选和键盘切换。对照 Git 哈希、父提交、提交文件和所选差异。 | Windows WebView 对 Debian x64、ARM64 两条主机入口读取真实提交。 |
| 分支与标签 | 标题栏、分支及标签管理、提交右键操作。对照本地引用、上游引用、切换结果和危险操作确认。 | Debian x64 WebView 代表场景及 Agent 协议套件。 |
| Git 远程、上游、拉取、推送、发布 | 标题栏、分支右键、设置上游、发布和命令面板。对照远程地址、跟踪引用、分歧、本地及上游 OID。需区分鉴权、拒绝和部分写入。 | Debian x64 两条主机入口真测首次发布、分歧拉取、部分同步和续推。无引用更新失败保留明确回执。 |
| 临时保存、合并与冲突、还原和拣选 | 临时保存与合并面板、历史右键、逐处和整文件操作、继续和中止。验证冲突文件、索引、序列状态和实际对象。 | Debian x64 和 ARM64 测试夹具，Agent 实际 Git 与部分 WebView 场景。 |
| 文件树、路径搜索、全文搜索、预览 | Files 工具栏、文件树右键、键盘快开和搜索。比较同一 SSH 位置的文本、二进制、嵌入资源、文件历史和搜索命中。 | Windows WebView 与 Debian x64、ARM64 核对大图、文档和搜索。协议覆盖裁剪、文件版本和祖先目录边界。 |
| 文件编辑和结构写入 | 新建、复制、移动、重命名、回收站和永久删除。保存后在远端核对实际内容、索引和版本冲突。 | Debian x64 和 ARM64 开发验证、Windows Agent 协议测试。Linux v9fs 保存回退实测，NFS 与 exFAT 未验。 |
| 忽略规则 | 改动、临时保存和 Files 右键分别加入 `.gitignore` 或 `.git/info/exclude`。用 `git check-ignore` 和两份文件核对范围。 | Windows WebView 经 Debian x64 确认两种范围。协议覆盖原回执重放及状态刷新。 |
| 系统打开、显示和复制路径 | 改动、历史、冲突和 Files 右键从当前仓库读取。普通文件及指向仓库内普通文件的链接分段复制到本机临时目录。目录在 Twiglane 文件树定位。复制完整路径返回 SSH 主机上的路径。 | Windows Agent 核对二进制分页、内容变化及越界拒绝。Debian x64 Agent 核对仓库内链接、越界链接、元数据链接和断链。Windows WebView 经 Debian x64 核对系统显示入口生成的本机二进制副本。 |
| 终端及关闭应用 | 状态栏、命令面板、文件右键插入路径、标签、分屏、重启与退出。核对 SSH 工作目录、运行命令、活动进程及取消或确认关窗。 | Debian x64、ARM64 的真实 SSH PTY 与 Windows WebView 标签、分屏。Windows WebView 经 Debian x64 取消关窗后保留指定 PID，确认后窗口和对应子进程均退出。Rust 核对退出事件优先于旧快照。SSH 终端使用文件树路径插入，本机文件拖入会提示对应入口。 |
| PR/MR | 开启设置后从当前分支面板打开，明确选择远程与目标。对照平台收到的来源分支、仓库及最终链接，验证令牌由桌面钥匙串管理。 | Windows Rust 用回环服务验证 GitHub、GitLab 和 Gitea 请求，另核对来源变化时不访问凭据。Windows WebView 经 Debian x64 打开仓库，向本机回环 Gitea 测试服务显式创建一次请求，核对收到的 `feature`、`main` 和结果链接，并从测试钥匙串删除令牌。实平台写入待发行验收。 |
| Cliora 审阅返回 | 带基线和无基线各打开一次，检查任务差异、历史与文件。分别回传已审阅、已提交、已合入，核对原任务和重复送达。 | 已有真实主机身份和基线证据。Cliora 主机簿打开使用开发连接器，已安装双应用的任务回传待验证。 |

macOS x64、macOS ARM64 与 Windows OpenSSH x64 主机需要正式验收环境。发行签名、普通安装路径、目标平台矩阵、逐项界面回放及两端已安装的任务回传由 T8 采集。仓库的历史报告不能作为本候选的通过凭证。

# 仓库加载与任务差异性能验证

环境：Windows x64，Node.js 22.23.4，Rust stable。基线提交：`3fc82ed662bd6dbb7d5a5cec98af2324c41159f1`。

## 已修复的开销

- 仓库弹层重复打开时，共享尚未结束的同一总览请求；请求结束后再打开仍重新读取状态，没有引入状态有效期缓存。关闭弹层后旧响应不得写回共享缓存。清理已不属于最近仓库的 HEAD、总览与确认记录。
- 总览读取绑定整批取消令牌。切换仓库取消读取时，整批结束，不再把取消当作某项失败后继续启动后续仓库的 Git 命令。每步仍走原有并发限制与 generation 校验。
- 状态解析借用 Git 输出、逐条遍历 NUL 记录，以栈上字段数组替代逐文件临时 Vec。完整状态与总览共享格式校验；总览直接累计数量，不再构造文件路径与 FileChange 列表。
- 任务单文件差异和审阅 token 只读取目标路径的状态，并复用该结果；保留分支头、起点祖先关系、generation 和路径边界校验。避免每次点击都读取整个仓库状态、计算全仓库 numstat、未跟踪文件行数及二进制大小。
- 任务详情隐藏时释放单文件差异，多文件差异停读并释放内容；任务文件队列与选择保留。关闭/切换后迟到的任务或差异响应不再落地。快速选择限制为两项在途读取和最后一次待执行请求。多选匹配使用 Set，刷新选择按路径 Map 查找。
- 任务分页防止重复点击并发读取同一页，复用通用分页合并函数保持起始 offset 和 hunk 元数据，避免后续页跳读。

同时检查了历史多文件差异、普通多文件差异、语法高亮与 Markdown：已有视口保留、缓存容量或 worker 生命周期控制。本次没有更改这些机制。压力用例中的历史多提交模拟接口已更新为当前使用的 `compareFiles` / `compareFileDiff`。

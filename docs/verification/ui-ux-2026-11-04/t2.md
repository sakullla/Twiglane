## 1. 方法

1. 读 T1 的 `baseline.md` / `baseline/manifest.json`，并在**未改动前**用 CDP 采集起始页与工作区的 DOM 几何与计算样式

   原始数据：`t2/measurements/t2-baseline.json`。
2. 按量到的偏差改 `src/styles/` 与 `StatusBar.svelte`，只动 T2 scope 内文件。
3. 改完用同一脚本再采一次（`t2/measurements/t2-after.json`），并用 `baseline-shots.mjs --out` 重新出 20 张截图。

> 局限：本会话没有图片查看能力（无 ViewImage/截图预览工具），**没有逐张贴图目视比对**。
> 判断依据是上表的可核对几何与对比度，加上截图产物供人工复核；`baseline.md` 里"截图只证明被截到的那一刻"同样适用。

## 3. 实际改动

- `src/styles/tokens.css`：新增三个共享度量 `--titlebar-control: 30px`、`--statusbar-height: 26px`、`--statusbar-hit: 24px`；
  没有新增颜色令牌、没有新增主题选择器。
- `src/styles/layout.css`
  - 标题栏：品牌按钮、仓库按钮、分支 pill、同步 pill、图标按钮共读 `--titlebar-control`（分支/同步从 28 收到统一的 30），
    于是两个下拉菜单顶端对齐；标题栏内焦点环改成 `outline-offset: -2px`，40px 条高里不再压到相邻控件。
  - 状态栏：条高读 `--statusbar-height`，按钮命中区读 `--statusbar-hit`（+ `min-width` 保方形）与 `--radius-sm`，
    焦点环同样收进条内；同步结论加 `.sb-sync` 取 `--fg-muted` 提一级；合并提示悬停保留警告语义色（之前会褪成一格中性灰）。
  - 起始页：`.welcome-section` 多 8px 上间距（组内 24 / 组间 32 的两段节奏）；最近仓库行名升到 `--text-base`；
    `@media (max-height: 720px)` 里把组间那档间距与列表行内边距让给内容（661–720 这段最紧）；
    新增 `@media (max-height: 660px)` 紧凑档（只收间距与图标块，条目数量与结构不变，行式卡片选择器写成 `.welcome .action-card`
    以盖过 `@media (max-width: 960px)`）；新增 `prefers-reduced-motion` 下取消卡片 1px 抬升。
- `src/styles/components.css`：`.menu` 最小宽度 255 → 268（同步项说明不再折行，菜单项同高）；`.btn-secondary` 去掉 `--shadow-sm`，
  与 `.field` / `.branch-pill` / `.action-card` 统一为「一条控件边界 + 表面填充」。
- `src/lib/components/StatusBar.svelte`：同步读数 span 增加 `sb-sync` 类（仅此一处，不改 DOM 结构与 ARIA）。
- `tests/sidebar.spec.ts`：新增 5 条外壳样式契约（标题栏同高、状态栏命中区、600 高紧凑档、菜单宽度、减少动效不位移），
  并在状态栏行为用例里断言同步读数挂在 `.sb-sync` 上。

没有改动 `App.svelte`、Git/Rust 行为、依赖、workflow state；没有提交。

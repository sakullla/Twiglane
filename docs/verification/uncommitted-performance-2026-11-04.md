# 本地未提交改动性能验证

日期：2026-11-04。环境：Windows、Node.js 22.23.4、Rust 1.99.1、Git 2.52.0.windows.1。

## 改动及依据

- 多文件差异原先一直保留所有浏览过的选中文件。现在只保留视口及上下 600px 预读范围内展开的内容，滚出、折叠或隐藏页面时释放内容和完成记录；迟到响应不能重新填入已释放的块。返回时重新读取，保留块高度与横向滚动位置。
- 读取轮次仍随仓库、generation、快照身份和上下文范围变化，但记录不再引用整份仓库快照，避免旧文件列表被间接持有。
- 刷新多选状态原先逐项构造完整分组列表。现在每次快照建立一次路径索引，总工作量为 O(文件数 + 选中数)，保留冲突、两侧变化、暂存后跟随另一侧及去重规则。
- Rust 差异分页原先先克隆全部显示行，再克隆当前页。现在仅克隆当前页，保留行号、代码块范围和部分暂存边界；解析 UTF-8 时直接借用输入，减少一份完整文本复制。

## 实测与检查

分页微基准：生成 50,000 行新增内容，预先完成解析，对开头、中间、末尾各取 400 行，重复 100 次，总计 300 页。使用相同 Windows 主机及 Rust debug test profile。

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 300 页显示数据构造耗时（单次运行） | 5.3525723 秒 | 23.878 毫秒 |

最终代码再次运行得到 26.8073 毫秒，数量级一致；未使用跨机器固定耗时阈值。

这只衡量 `view_lines` 的分页构造，不包含 Git 进程、差异解析、IPC、语法高亮或 WebView 渲染，也不是整机内存测量。

- `npm run check`：0 错误、0 警告。
- `npm test`：27 个测试文件，665 项通过。
- `npm run build`：通过；保留大型语法资源 chunk 的体积提示。
- `cargo test --locked --manifest-path src-tauri/Cargo.toml`：146 项通过，包括真实 Git 的部分暂存、过期补丁拒绝及二进制差异。
- `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`：通过。
- `npm run test:performance -- --ui`：8 项通过。新增 20,000 文件路径读取次数断言、远距离跳转、并发上限及隐藏后的响应隔离检查。
- 分页微基准通过；分页回归覆盖跨块分页、页末、越界、空差异及截断块不能部分暂存。

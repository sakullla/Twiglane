# v0.2.17 验证记录

## 内存与性能

- 历史“全部文件”只保留视口和预读范围内展开的差异，离开范围或收起后释放；换提交清除旧高度记录。隐藏后重开相同提交仍按新轮次读取，迟到响应不会重新填入旧内容。
- 高亮最多同时运行两个任务；等待任务可以取消，取消运行任务后等 Worker 确认再复用槽位。单文档最多传入 60,000 行、2,097,152 个 UTF-16 码元（含行分隔），超出部分保留原文，按纯文本显示。已有 8 MiB 估算缓存预算和 30 秒空闲释放 Worker 规则保留。
- 切到历史页释放本地单文件差异；提交所在分支查询只保留最新待执行项，并在隐藏、销毁、缓存命中时隔离旧请求，避免重复读取和错误覆盖。
- 完整本地补丁不再额外运行 numstat；截断补丁仍核对全量行数。状态中的两侧统计并发读取，未跟踪文件统计在阻塞线程按单文件 2 MiB、单次刷新 16 MiB 预算执行。超过预算的列表行数为空，文件及其差异入口保留。
- 刷新得到相同补丁时复用行数组，减少重复排版和分词。

这些是资源上限、生命周期和调用次数的验证，没有测量原生应用常驻内存或长期堆增长，不宣称固定的 RAM 降幅。

## 同版本包含的功能

本版本同时包含工作区已有的分支、合并和同步改动：查看提交所在分支、合并前逐提交/逐文件审阅、远程短名冲突时另取本地名、指定远程推送及取消远程操作、仓库列表显示当前分支，以及相关界面调整。远程操作取消后按真实刷新状态显示，不假设远程没有收到请求；Git 写入仍保持序列化、generation 校验和参数数组调用。

## 性能样例

真实 Git 夹具，test/debug 构建，同机单次测量，不是 P95：

| 场景 | 耗时 |
| --- | ---: |
| 5,002 分支完整状态 | 1,560 ms |
| 5,002 分支轻量列表 | 866 ms |
| 20,000 文件大小批量读取 | 1,376 ms |
| 20,000 文件提交详情 | 3,592 ms |
| 两个文件差异（含 5,000 行） | 158 ms |
| 20,000 文件合并预览 | 311 ms |
| 20,000 文件真实快进合并 | 14,542 ms |
| 50,000 行差异生成 300 页 | 26 ms |
| 连续 10 次未提交差异读取 | 835 ms，10 次 git diff |
| 含 104 MB 未跟踪文本的 3 次状态刷新 | 208 ms |

修改前后对比见 [本地未提交验证记录](../uncommitted-performance-2026-11-05.md)。大文件刷新提速包含“列表不全量统计大文件行数”的行为取舍；高亮超预算只省略着色，不省略文本。
